684년, 여러 왕국과 공국이 존재하는 중세 판타지 세계.
귀족과 기사, 마법사와 상인, 평민이 각자의 삶을 살아가는 가운데 대륙 곳곳에는 마물이 출몰한다.
대륙 최북단에 자리한 발테르 공국은 혹독한 추위와 마물의 위협 속에서 오랜 세월 발테르가가 통치해 온 북부 영지다.
